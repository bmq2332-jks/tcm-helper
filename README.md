> 中醫及傳統整復 — 疑難雜症智慧解答工具（**症狀知識庫 ＋ 電療・熱敷處置建議**）

## 使用方式

直接開啟 GitHub Pages 網址即可使用：

**👉 https://bmq2332-jks.github.io/tcm-helper/**

### 功能

- 輸入症狀即可獲得中醫辨證論治建議
- 涵蓋經絡穴位、傳統整復、藥膳食療
- **25 大類常見症狀知識庫（含 A型流感）**
- 每個症狀結果卡附 ⚡電療 / ♨️熱敷 處置建議 — 依症狀量身撰寫（部位、強度、時間、禁忌）
- 免安裝、免登入、直接使用

### V3 新增
