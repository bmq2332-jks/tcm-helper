## 使用方式

直接開啟 GitHub Pages 網址即可使用：

**👉 https://bmq2332-jks.github.io/tcm-helper/**

### 功能

- 輸入症狀即可獲得中醫辨證論治建議
- 涵蓋經絡穴位、傳統整復、藥膳食療
- **24 大類常見症狀知識庫**
- **💡 療法查詢：電療、熱敷療法（V3 新增）** — 含適用對象、操作方式、禁忌症、安全提醒
- 免安裝、免登入、直接使用

### V3 新增

- **電療（低頻/中頻電刺激）**：經絡疏通、鎮痛解痙；完整禁忌症（心律調節器、懷孕、癲癇等 9 項）
- **熱敷療法**：溫經散寒、活血通絡；完整禁忌症（急性損傷 48-72hr 內、糖尿病、燙傷風險等 8 項）
- 症狀 / 療法雙模式切換 UI
